# Annly

Plataforma de gestión para negocios de servicios.

## Entornos

- `main` → Producción
- `develop` → Desarrollo

## Modelo

Annly utiliza un modelo de:

- Planes
- Features
- Módulos adicionales
- Add-ons

## Planes

### BASIC
$14/mes

### MEDIUM
$29/mes

### ULTIMATE
$49/mes

## Módulos

Los módulos pueden estar incluidos en un plan o contratarse de manera independiente.

Ejemplo:

Finanzas → +$20/mes
